---
description: Identify, investigate, and fix bugs or syntax errors in the codebase.
---

1.  **Investigate**: Analyze error messages or user reports to locate the root cause.
2.  **Reproduce**: If possible, reproduce the issue or confirm it through file inspection.
3.  **Implement Fix**: Address the issue using focused code changes.
4.  **Verify**: Run appropriate build commands or tests to ensure the fix works and doesn't break anything else.
5.  **Clean up**: Remove any debug statements or unused code related to the fix.
