description: Create a detailed technical implementation plan for a new feature or complex change.
---

1.  **Understand Requirements**: Clarify the feature scope and user needs.
2.  **Architect**: Decide on the necessary database changes, API routes, and frontend components.
3.  **Draft Plan**: Create an `implementation_plan.md` artifact detailing the proposed changes.
4.  **Review**: Request user feedback on the plan before proceeding to execution.
