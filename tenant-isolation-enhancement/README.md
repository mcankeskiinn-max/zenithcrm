# Tenant Isolation Enhancement

Bu paket, tenant izolasyonu icin kalan guvenlik kontrollerini tamamlamak icin
hazir analiz, script ve ornek kodlari icerir.

## Nasil Kullanilir
- analysis/ altindaki raporlar ile risk/oncelik belirle.
- scripts/ altindaki denetim scriptlerini stagingde calistir.
- migrations/ altindaki SQL, DB seviyesinde guclendirme icindir.
- docs/ dosyalari ekiplere dagitilir.
